# AESTHETIC DIRECTION — MATCH `oralign-reference.html` EXACTLY

This is the most important section. The reference HTML is editorial, premium, and category-disrupting. **Reject every generic SaaS landing page convention.** No purple gradients, no `Inter`, no pure-white backgrounds, no rounded-3xl glassmorphism cliché.

### Color System (use these tokens — port them into Tailwind theme + `globals.css`)
```
--black: #0a0a0a        /* dominant on dark sections */
--white: #f8f6f2        /* warm off-white, NEVER pure #fff */
--sun: #f5c842          /* golden primary accent */
--sun-2: #f9d96a        /* lighter golden */
--sun-3: rgba(245,200,66,.12) /* sun glow */
--grey: #e8e4de         /* warm divider grey */
--mid-grey: #c4bfb6
--text-dark: #1a1a1a
--text-mid: rgba(10,10,10,.55)
```
Dark sections are **near-black with golden accents**. Light sections are **warm off-white**. Alternate them. One section is **pure golden background** (manifesto) for visual punctuation.

### Typography
- **Display / Headings:** `Playfair Display` (weights 300, 400, 500, italic 300/400) — load via `next/font/google`. Use **italic for emphasis words** (e.g. "*revealed*", "*precision*", "*shine*").
- **Body / UI:** `DM Sans` (weights 200, 300, 400, 500) — load via `next/font/google`.
- Headings: weight 300, line-height 1.08, font-size `clamp(2rem, 3.5vw, 3.6rem)`.
- Body: weight 300, line-height ~1.95, color `var(--text-mid)`.
- Eyebrow tags: 0.55rem, letter-spacing 0.42em, uppercase, with a 18px line before.
- **NEVER use Inter, Roboto, system-ui, or any generic sans.**

### Signature Visual Elements (port these from reference, adapt to platform)

1. **Custom cursor** — small black dot + larger ring (32×32, 1.5px border). Inverts to white on dark sections. Scales up on hover. Hidden on touch devices via `@media (pointer: coarse)`. Build as `<CustomCursor />` client component, mounted only on `lg+` viewports.
2. **Sun burst SVG** — radial sun with rays + concentric circles, used as background in hero and CTA. Component: `<SunBurst variant="hero" | "core" | "subtle" />`.
3. **Sun core disc** — golden radial-gradient circle with shadow glow, used as hero right-panel centerpiece. **Replace the "ORALIGN" wordmark inside the disc with the platform logo + brand name from this app.** Slow rotation (40s linear infinite) on the rays.
4. **Reveal animation** — `.rv` class: opacity 0 → 1, translateY 24px → 0, transition 0.8s ease, triggered by IntersectionObserver at threshold 0.08. Stagger pairs with `.rv2` (0.15s delay).
5. **Marquee ribbon** — black strip between hero and brand section, infinite horizontal scroll, gold dots between items, items uppercase 0.55rem letter-spacing 0.38em.
6. **Hover state on cards** — bottom border scales from 0 → 100% in golden, background tints to `#fdf9ec`.
7. **Section eyebrow tag** — `.stag` with 18px gold line before the label.
8. **Italic emphasis in headings** — every section headline has at least one italic word in a different shade or `var(--sun)`.
9. **Noise grain on dark sections** — SVG fractalNoise filter at ~0.06 opacity, 0.25 layer opacity.
10. **Multilingual switch** — top-right FR / EN / AR pills. AR triggers `dir="rtl"`. Implement as `next-intl` or `next/navigation`-based locale routing if it fits the existing app; otherwise client-side switch using a translation dictionary in `lib/i18n/dict.ts`.

# TECH STACK

- Next.js (App Router) + TypeScript + Tailwind CSS + shadcn/ui
- Server Components by default; `"use client"` only where genuinely required (cursor, lang switch, mobile sheet, accordion, tabs, IntersectionObserver reveals)
- `next/font/google` for Playfair Display + DM Sans
- `next/image` for all bitmap imagery (the reference uses SVG mockups — keep that approach, no stock photos)

- Strictly typed; no `any`; props interfaces exported from each component
- Zero backend logic except a stub server action for the contact form (`app/(marketing)/actions.ts`) that validates with Zod and returns `{ ok: true }`
- Marketing site lives in `app/(marketing)/` route group with its **own layout** so it does not inherit dashboard chrome
- **Do not modify, break, or share state with any existing dashboard route, middleware, or auth.**

Performance:
- All images via `next/image` with explicit width/height (no CLS).
- Below-the-fold heavy sections (Manifesto SVG, CaseLifecycle): dynamic import with `ssr: false` only if measurably needed.
- Custom cursor: `lg+` viewports only, preference-respect `prefers-reduced-motion`.
- **Lighthouse target on homepage: Performance ≥ 95, A11y ≥ 95, SEO = 100, Best Practices ≥ 95.**

# UI/UX RULES

- Mobile-first: 375px → 768px → 1024px → 1440px.
- Container: `max-w-[1400px] mx-auto px-6 lg:px-[72px]` (matches reference 72px gutter on desktop).
- Section rhythm: `py-20 lg:py-[120px]`.
- Focus rings: `outline-2 outline-offset-2 outline-[var(--sun)]` — gold and visible.
- WCAG AA contrast minimum on all text (verify against `--text-mid` on `--white`).
- Mobile nav (Sheet) animates from right, gold underline on active link.
- Cards: 1px hairline border `var(--grey)`, subtle shadow `0 1px 3px rgba(0,0,0,0.04)`, **no rounded corners larger than `rounded-md`** — reference uses sharp edges (editorial code).
- Buttons: Primary = solid gold with -2px hover lift; Secondary = ghost with arrow extension on hover (40px); Tertiary = black solid on light sections.
- Animations: hero load stagger (0.15s, 0.3s, 0.45s, 0.6s delays), `.rv` reveal on scroll, marquee infinite, sun-rays slow rotate. **No parallax, no scroll-jacking.**
- `prefers-reduced-motion`: disable cursor, marquee, sun rotation, reveals (just opacity 1 directly).
